From raw timestamps to a scoped study

Four steps. Each runs in the browser on open data, and each is open to inspection.

  1. 1

    Decompose

    About 67,000 actual-vs-scheduled timestamps a day, timed to the second. The delay each train gains on every run and at every stop is split into created and recovered.

  2. 2

    Fingerprint

    A robust Theil–Sen fit of delay-out against delay-in per section gives α (delay created on its own) and β (does the section absorb or amplify delay?), with bootstrap 95% CIs.

  3. 3

    Price

    Passenger-hours × value of time, with empirical-Bayes shrinkage so small samples can't top the ranking. Knock-on leverage shows where one minute saved is worth most.

  4. 4

    Recommend

    Fintraffic cause codes and the fingerprint map each section to an intervention and a Sweco service. Claude writes the memo, the tender input or the technical note.

Value for Finland's railway

Each output answers a question a client already pays to have answered.

  • Väylävirasto (Finnish Transport Infrastructure Agency)Which sections to double-track, add passing loops to or renew first, ranked by € evidence and ready to scope as a feasibility study.
  • FintrafficWhere delay amplifies (β>1) and spreads across the network, as input to timetable robustness and traffic management.
  • VR and operatorsStations where dwell overruns create delay, to inform platform design and boarding flows.

Built for the long run

Each period's section fingerprints are saved to a shared history. Over weeks this becomes a baseline that flags sections getting worse (β rising, infrastructure causes growing) before they become a crisis.

The result is a recurring network-health service instead of a one-off study.
